# Sources, attribution and scientific basis

MedCLIPSeg++ evaluates an uncertainty-based review rule for frozen breast ultrasound segmentations and connects it to a reference-case search application. The guide identifies the external work reused at each stage, the publications and standards that explain the design, and the local evidence for the choices made here.

- The frozen segmentation backbone and dataset configurations are adapted from MedCLIPSeg by Taha Koleilat, Hojat Asgariandehkordi, Omid Nejati Manzari, Berardino Barile, Yiming Xiao, and Hassan Rivaz. Local adaptations include configurable paths, raw entropy export and evaluation runners. [CVPR 2026 paper](https://openaccess.thecvf.com/content/CVPR2026/html/Koleilat_MedCLIPSeg_Probabilistic_Vision-Language_Adaptation_for_Data-Efficient_and_Generalizable_Medical_Image_CVPR_2026_paper.html) · [Upstream code](https://github.com/HealthX-Lab/MedCLIPSeg) · [Released weights](https://huggingface.co/TahaKoleilat/MedCLIPSeg) · [Local model code](shared/medclipseg) · [Local dataset configurations](shared/configs) · [Upstream Apache-2.0 license](https://github.com/HealthX-Lab/MedCLIPSeg/blob/main/LICENSE) · [Local license copy](shared/LICENSE-MedCLIPSeg).
- The visual embedding workflow uses [UniMedCLIP](https://github.com/mbzuai-oryx/UniMed-CLIP). Original model checkpoint terms apply to downloaded weights.
- Predicate-Aware Block Pruning is attributed to the [pabp-filtered-ivf project](https://github.com/Fergarciamedina/pabp-filtered-ivf). The application uses a local integration.
- The five ultrasound cohorts use the MedCLIPSeg prepared partitions. Each original dataset publication is credited in the study input guide. Follow each provider's data access and redistribution terms. [Study dataset sources](research/stage_1/STUDY_INPUTS.md#dataset-sources) · [Prepared data release](https://github.com/HealthX-Lab/MedCLIPSeg/blob/main/assets/DATASETS.md).
- The [Stage 4 research](research/stage_4/SELECTIVE_PREDICTION_STUDY.md) documents the contribution and its relationship to prior work.

Third-party notices in the vendored source continue to apply.

## Sources by stage

| Stage | External work used | Decision and evidence |
| --- | --- | --- |
| 1 · Inputs | The original cohort releases supply images and annotations. MedCLIPSeg supplies the prepared partitions and lesion descriptions. [Dataset sources](research/stage_1/STUDY_INPUTS.md#dataset-sources). | Retain one modality and reuse cached outputs within the available compute budget. The catalog follows CSV conventions and uses SHA-256 for raster identity. [Dataset counts, hardware and checks](research/stage_1/STUDY_INPUTS.md#how-many-cases-were-used) · [Input contract and standards](application/stages/stage1_inputs/APPLICATION_INPUTS.md). |
| 2 · Intent routing | Reused router from an external contributor. The original author and source are pending verification. [Implementation credit](application/stages/stage2_intent_router/INTENT_ROUTER.md#implementation-credit). | Fixed rules cover a small set of actions and extract a result count. Weizenbaum, Thompson and Bocklisch et al. provide context for keyword dispatch, regex matching and separating intent from arguments. [Papers and regression checks](application/stages/stage2_intent_router/INTENT_ROUTER.md#research-background-and-design-basis). |
| 3 · Segmentation | MedCLIPSeg supplies the model, architecture and released weights. [Frozen model settings and sources](research/stage_3/FROZEN_SEGMENTATION.md). | Keep predictions fixed to isolate the score comparison. Document the model grid, resampling, stochastic sample count and aligned artifact export. [Inference and image-processing rationale](research/stage_4/study_reference/EXPERIMENTAL_RATIONALE.md#backbone-and-digital-image-processing). |
| 4 · Selective prediction | Prior work motivates structure-wise entropy aggregation, spatial comparisons and risk–coverage evaluation. [Methodological sources](research/stage_4/SELECTIVE_PREDICTION_STUDY.md#methodological-sources). | Compare seven scores, select the local cutoff on BUSI validation and evaluate the frozen rule on held-out and external cohorts. [Archived results and policy](research/stage_4/experiments/RESULTS_GUIDE.md). |
| 5 · Similarity retrieval | UniMedCLIP supplies the embeddings, FAISS supplies search primitives, and PABP supplies the pruning approach. [Retrieval sources](application/stages/stage5_similarity_retrieval/SIMILARITY_SEARCH.md). | Use Stage 4 acceptance as the eligibility predicate. Test full-probe retrieval against exact filtered search and document the cost and recall implications of probing fewer lists. [Search rationale and evidence](docs/architecture/DESIGN_RATIONALE.md#vector-search-and-predicate-aware-block-pruning). |
| 6 · Output | React and FastAPI support the local dashboard. Shneiderman's overview-and-detail principle provides interface design context. [Dashboard output guide](application/stages/stage6_system_output/DASHBOARD_OUTPUTS.md). | Project the mask with nearest-neighbor resizing to preserve label values. Expose the image, review decision and reference results as distinct outputs. [API tests](application/medical_dashboard/backend/tests/test_api.py). |
