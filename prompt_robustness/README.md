## 1. Research Overview

This contribution hosts an independent line of research within the group's evaluation of MedCLIPSeg. While the uncertainty track investigates post-hoc uncertainty quantification and selective prediction, the **prompt robustness track** examines the model's sensitivity to linguistic variations, clinical phrasing styles, and text perturbations.

---

## 2. Objectives & Research Scope

1. **Prompt Sensitivity Quantification:** Measure how variations in prompt phrasing (e.g., standard clinical terminology, descriptive syntactic expansions, abbreviations, or lexical perturbations) affect segmentation metrics (DSC and NSD).
2. **Cross-Center Realism:** Assess whether model performance degrades when presented with prompt phrasing styles typical of different radiological centers.
3. **Synergy with Uncertainty:** Provide perturbed prompt scenarios to verify whether uncertainty metrics in `uncertainty_rejection/src/uncertainty/` accurately signal text-induced segmentation degradation.

## 4. Interaction with the Shared Baseline

- **Zero Duplication:** All experiments rely directly on the frozen baseline in `shared/medclipseg/`.
- **Inference Entry Points:** Custom prompt designs are passed via `--prompt_design <name>`, reading text prompt Excel files from `Prompts_Folder/Test_text_<name>.xlsx`.
- **Output Isolation:** Experimental outputs generated by prompt experiments should be directed to `data/outputs/prompt_robustness/` outside Git tracking.
