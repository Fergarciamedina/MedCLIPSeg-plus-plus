# Track: Text-Prompt Robustness and Perturbation Analysis

**Collaborator / Track Lead:** Ehsan
**Course:** ELEC 6661 — Medical Image Processing (Fall 2026)
**Baseline Model:** MedCLIPSeg (CVPR 2026, Koleilat et al.)
**Status:** Planned / Documented Track

---

## 1. Overview and Scope

This track represents an independent, complementary line of research within the group's evaluation of MedCLIPSeg. While the uncertainty rejection track investigates post-hoc failure detection and selective prediction via pixel-level entropy, the **prompt robustness track** evaluates the model's sensitivity to linguistic variations, phrasing styles, and perturbations in clinical text prompts.

> [!NOTE]
> This directory is reserved for Ehsan's experimental scripts, prompt configuration files, and robustness evaluation results. No existing code is overwritten during the project scaffolding refactor.

---

## 2. Research Objectives

1. **Prompt Sensitivity Analysis:** Quantify how variance in text prompt phrasing (e.g., standard clinical terminology, descriptive syntactic expansions, abbreviations, or lexical substitutions) impacts segmentation quality (DSC and NSD).
2. **Clinical Realism:** Evaluate whether the model's reliance on specific prompt templates introduces brittleness when applied to clinical reports generated across different hospital centers.
3. **Cross-Track Synergy:** Provide perturbed prompt scenarios to test whether raw uncertainty estimates correctly reflect degradation induced by sub-optimal or out-of-distribution text prompts.

---

## 3. Shared Infrastructure and Execution

To avoid code duplication across the team:
- The prompt robustness track shares the core inference engine in `shared/medclipseg/`.
- Prompt design flags (such as `--prompt_design`) in `shared/medclipseg/test.py` allow custom prompt files (e.g., `Test_text_<prompt_design>.xlsx`) stored in `Prompts_Folder/`.
- Outputs generated by prompt experiments should be directed to `data/outputs/prompt_robustness/` outside the public Git repository.
