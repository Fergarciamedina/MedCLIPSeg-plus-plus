1 · Study inputs

Which pixels belong to the lesion?

Start with two dark regions in a grainy image. The lesion description identifies a target. Its reference mask represents an annotation of the target region. A predicted outline can include extra pixels (false positives) or miss part of the lesion (false negatives).

Dice (DSC) measures overlap as twice the shared area divided by the sum of the predicted and reference areas. Normalized Surface Dice (NSD) measures what fraction of the two contours falls within a chosen distance of the other contour. High overlap can coexist with a displaced boundary. You can adjust the distance and see both measures in chapter 3.

The study uses the prepared MedCLIPSeg breast ultrasound partitions. There are 78 BUSI validation images, 78 held-out BUSI images and 464 external images from UDIAT (25), BUID (35), BUSUC (122) and BUSBRA (282). Preparation checks record membership, image and annotation pairing, prompts and usable artifacts. The study uses one modality and reuses frozen outputs across methods to fit the inference budget and keep the comparison paired. The counts come from the available partitions.

3 · MedCLIPSeg

One image and prompt, many predictions

A deterministic segmentation network in ordinary inference returns the same output for fixed inputs and weights. MedCLIPSeg encodes the image and the lesion description, then uses probabilistic cross-modal attention to let the two influence each other. It samples attention value features, so repeated passes can yield different predictions even with fixed inputs. This is the upstream model of Koleilat et al. MedCLIPSeg++ reuses its published weights.

Image + lesion description → 30 stochastic passes → Mean probability per pixel → Mask + predictive entropy

What does an uncertain pixel mean?

Given an image and a fixed lesion description, MedCLIPSeg averages stochastic model outputs to estimate the probability p that a pixel belongs to the lesion. We use 30 samples and mark the pixel as lesion when p exceeds 0.5.

H(p) = −p ln p − (1 − p) ln(1 − p)

Derive the link to error

The model assigns its chosen label probability max(p, 1 − p), so its implied probability of error is q = min(p, 1 − p). Binary entropy is symmetric, so H(q) = H(p). For 0 < q < 0.5, H′(q) = ln((1 − q)/q) > 0. The link is monotonic under the model. The relationship to observed errors is a separate empirical question.

Figure S5 in the original paper reports that higher uncertainty bins had higher observed pixel-error rates. Calibration would additionally compare quantities such as q = 0.2 with a 20% observed error rate across comparable predictions. Scan-level Dice asks a different question.

4 · Research contribution

Selective segmentation review

The goal is to rank completed masks for review without requiring a reference annotation at runtime. Our hypothesis was that pixels inside the predicted lesion would provide a stronger signal about mask quality than averaging over the entire frame. Region choice matters. An ambiguous boundary can belong to a good mask, and a missed region contributes no pixels to a foreground-only mean.

Derive why foreground entropy can track Dice

Let F be the predicted lesion and G the reference. Dice loss is (FP + FN)/(|F| + |G|). Within F, an error is a false positive, and the model-implied expected count is Σi ∈ F(1 − pi). On predicted foreground, entropy increases as the model's chance of a false positive increases.

DSC = 2(P − FP)/(2P − FP + FN), with P = |F|

Holding P and FN fixed, the derivative with respect to FP is −2(P + FN)/(2P − FP + FN)2, which is negative for a nonempty prediction. Together these facts explain why foreground entropy can be associated with lower Dice.

The Dice denominator varies across scans, false negatives are outside F, and confidence can be miscalibrated. The average of entropy and the average probability of error can also rank scans differently. These are reasons to test the relationship on data.

At one threshold, coverage is the fraction retained and risk is the average loss among the retained masks. AURC summarizes this loss across coverage levels. Lower values indicate that the ranking tends to keep better masks at the measured coverage levels. The paired bootstrap resamples the same validation scans for both methods when estimating uncertainty in their AURC difference.

5 · Similarity retrieval

Search within eligible reference cases

When a catalog match passes the review rule and the user asks for similar cases, the system searches among accepted reference cases. Each scan has a 512-dimensional, unit-normalized UniMedCLIP visual embedding. The dot product between two such vectors is cosine similarity.

A full search would score every eligible reference. FAISS’s inverted file (IVF) first chooses the nprobe nearest clusters. Within those lists, Predicate-Aware Block Pruning (PABP) reads an eligibility summary for each block. A block containing only cases marked for review is skipped before computing any vector distances. In a mixed block, only eligible IDs are scored. The query itself is excluded.

    Synthetic vectors and review labels. An unprobed list can contain an eligible case more similar than any result already found.

    The research contribution supplies the eligibility signal. PABP comes from a separate project. The integration is checked against exact filtered search at full probe and tests eligibility, with no clinical relevance or retrieval speed claim from this example.
