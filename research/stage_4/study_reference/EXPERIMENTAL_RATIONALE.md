# Experimental rationale for Stage 4

Stage 4 asks whether uncertainty from frozen MedCLIPSeg predictions can rank segmentation errors and support selective review in breast ultrasound. Every aggregation runs on the same mask and predictive entropy map for each case. Keeping the checkpoint, prompt, raster and outputs fixed isolates the effect of the score and selection rule within this experimental comparison. The [protocol](EXPERIMENTAL_PROTOCOL.md) gives the full procedure. The [system rationale](../../../docs/architecture/DESIGN_RATIONALE.md) explains the application and vector search.

## Cohort scope and sample sizes

BUSI is the source domain for the frozen checkpoint. The study uses the breast-ultrasound partitions distributed with MedCLIPSeg. Retaining the modality and organ while changing dataset tests whether the operating point transfers under changes in sources, scanners and annotation practices. These factors vary together, so the comparison cannot identify a single cause of coverage drift. [MedCLIPSeg domain generalization experiment](https://tahakoleilat.github.io/MedCLIPSeg/) and [upstream data manifest](https://github.com/HealthX-Lab/MedCLIPSeg/blob/main/assets/DATASETS.md).

| Cohort | Images | Basis for inclusion and interpretation |
| --- | ---: | --- |
| BUSI validation | 78 | Source-domain partition for selection and threshold calibration. The main analysis uses 65 cases with nonempty predictions. The remaining 13 support the observed empty-mask analysis. The full original BUSI release has 780 images. [Al-Dhabyani et al.](https://doi.org/10.1016/j.dib.2019.104863). |
| BUSI locked test | 78 | Separate source-domain partition used after freezing the rule. There were 65 nonempty predictions and 13 empty predictions in the saved artifacts. [Primary test table](../experiments/locked_busi_test/results/primary_operating_point_test.csv). |
| UDIAT test | 25 | External acquisition source. One decision moves the cohort coverage by 4 percentage points, which limits the precision of coverage estimated from this split. [Yap et al.](https://doi.org/10.1109/JBHI.2017.2731873). |
| BUID test | 35 | Separate external source and upstream test partition. One decision moves coverage by about 2.86 percentage points. [Dataset source cited by MedCLIPSeg](https://www.sciencedirect.com/science/article/pii/S0010482522011465). |
| BUSUC test | 122 | Larger external partition in the same modality. It provides finer within-cohort numerical resolution than UDIAT and BUID. [Dataset source cited by MedCLIPSeg](https://www.sciencedirect.com/science/article/pii/S0952197623014768). |
| BUSBRA test | 282 | Largest external partition and a source dataset with multiple scanners. Its 282 images contribute 60.8% of the pooled external estimate. [Gómez-Flores et al.](https://doi.org/10.1002/mp.16812). |

The audit counted all six prepared folders and found zero shared PNG filenames across the two BUSI splits. Patient-level independence remains unverified. The application gallery has 542 test images. The primary nonempty-mask test analyses use 65 BUSI and 464 external cases, or 529 combined. The 78 validation images are separate. Reporting both a pooled external result and an unweighted cohort average makes the effects of unequal cohort size visible. [Dataset protocol](EXPERIMENTAL_PROTOCOL.md) and [cross-domain table](../experiments/external_test/results/cross_domain_summary.csv).

The available hardware motivated bounding the study to one modality and a single frozen checkpoint, and reusing offline outputs for the repeated analyses. The exact case counts come from the upstream splits. There is no measured maximum cohort size or prospective power calculation in the run records. Using every image of each chosen partition also avoids a second, potentially outcome-dependent subsampling decision.

Speckle in B-mode images arises from coherent interference of scattered echoes and can mask small intensity variations. Changes in acquisition and image processing can alter lesion contrast, small-boundary visibility and background texture. These mechanisms motivate using several external ultrasound cohorts. The available case metadata do not let the study attribute a measured score difference to speckle or to any particular scanner setting. [Burckhardt, *Speckle in Ultrasound B-Mode Scans*](https://cc.kangwon.ac.kr/~mhchoi/lecture/biomedical/Burckhardt%281978%29%20Speckle%20in%20Ultrasound%20B-Mode%20Scans.pdf).

## Hardware and execution budget

The protocol records Apple Silicon M4 and PyTorch MPS. The validation launcher uses batch size 8 and the test runner uses 32. Both study configurations use a 224 × 224 grid and 30 stochastic predictions per image. A smaller batch keeps fewer image activations and dense outputs live at once. The records do not establish a measured optimum for either batch size. [Protocol](EXPERIMENTAL_PROTOCOL.md), [validation launcher](../experiments/validation_selection/run_validation_inference.sh), [test runner](../../../shared/medclipseg/test.py), and [PyTorch MPS backend](https://docs.pytorch.org/docs/stable/notes/mps.html).

For one foreground channel in float32, sampled logits alone require `4TBHW` bytes for `T` draws, batch size `B` and raster `H × W`. With `T=30` and `H=W=224`, this is about **45.9 MiB at batch 8** and **183.8 MiB at batch 32**. The model, feature activations, sigmoid outputs, stack copies, transfers and allocator add memory. The available UniMedCLIP and segmentation checkpoint files measured approximately 2.19 GiB and 0.94 GiB on disk. Neither estimate is a peak-memory measurement.

Across 620 validation and test images, 30 retained draws per image yield 18,600 sampled logit maps. Keeping one final float32 entropy map per image requires about 118.7 MiB of array payload. Saving masks and maps makes the seven aggregation methods, risk–coverage analyses and bootstrap intervals repeatable on CPU without rerunning the network. The frozen checkpoint and execution without gradient tracking avoid training-state and gradient storage. The vendored model still repeats its stochastic feature and segmentation calculation for each retained draw. Changing the number of draws or preprocessing can move the entropy distribution and should be evaluated before reusing the cutoff. The study used 30 draws and a 224-pixel grid for upstream compatibility and a tractable execution budget. The seed 666 identifies the saved run and checkpoint convention. It has no statistical advantage over another seed. A convergence, resolution, or peak-memory sweep would be needed to justify optimality. [Model forward pass](../../../shared/medclipseg/trainers/medclipseg_unimedclip.py), [reference configuration](../../../shared/configs/BUSI.yaml), and [PyTorch reproducibility notes](https://docs.pytorch.org/docs/stable/notes/randomness.html).

Under independent conditional draws, the standard error of the sample mean probability at a pixel decreases as `1/√T`. That scaling does not establish convergence for the nonlinear entropy score or for its downstream ranking. A 224 × 224 raster with 16 × 16 ViT patches has 196 spatial tokens. Doubling each raster axis gives four times as many spatial tokens and sixteen times as many token-pair scores in a dense self-attention layer. This is a complexity comparison for attention, not a measured end-to-end speedup. [ViT architecture](https://arxiv.org/abs/2010.11929).

## Backbone and digital image processing

**Use a source model with both required outputs.** MedCLIPSeg provides text-guided segmentation and a spatial uncertainty signal through probabilistic vision–language adapters. A single frozen UniMedCLIP ViT-B/16 variant controls for changes in baseline quality and avoids the compute cost and additional estimand of retraining. The inspected inference code is in evaluation mode and samples attention values by reparameterization. Gal and Ghahramani's MC-dropout method is related uncertainty literature. The local source of randomness for this experiment is probabilistic attention. [MedCLIPSeg](https://openaccess.thecvf.com/content/CVPR2026/html/Koleilat_MedCLIPSeg_Probabilistic_Vision-Language_Adaptation_for_Data-Efficient_and_Generalizable_Medical_Image_CVPR_2026_paper.html), [UniMedCLIP](https://arxiv.org/abs/2412.10372), [Gal and Ghahramani](https://proceedings.mlr.press/v48/gal16.html), and [attention implementation](../../../shared/medclipseg/trainers/layers.py).

**Resample intensities and labels according to their data types.** The loader bicubically resamples image intensity to the source model grid and applies its CLIP normalization. Bicubic reconstruction combines neighboring intensity samples. A binary mask is categorical, so nearest-neighbor resampling selects an existing label and avoids fractional classes. The web overlay uses that rule when projecting a full-frame prediction back to the source raster. This assumes the original and mask cover the same frame. Resizing can distort aspect ratio and alter small contours and ultrasound texture. Enlarging the result cannot restore detail absent from the 224 × 224 prediction. Keeping the upstream transform controls a possible source of variation across aggregators. [Keys, cubic convolution interpolation](https://doi.org/10.1109/TASSP.1981.1163711), [model transform](../../../shared/medclipseg/datasets/dataloader.py), and [evaluation resampling](../../../shared/medclipseg/utils/eval.py).

**Store entropy in raw floating-point units.** For pixel `i`, the runner averages sampled foreground probabilities `p̄ᵢ = T⁻¹ Σₜ sigmoid(zₜᵢ)`. The 0.5 decision selects the larger of the two class probabilities under symmetric pixelwise misclassification costs. It is supplied by the baseline and has no claim of optimizing lesion recall or Dice. The runner computes `Hᵢ = −p̄ᵢ ln(p̄ᵢ) − (1−p̄ᵢ) ln(1−p̄ᵢ)` and forms the mask using `p̄ᵢ > 0.5`. Bernoulli entropy is maximal at 0.5 and ranges mathematically from 0 to `ln 2` nats. The implementation offsets the logarithms for numerical stability. Entropy of the mean measures total predictive ambiguity. Separating within-draw entropy from between-draw disagreement would need the individual draw information. The score uses the aligned float32 map and binary mask. A normalized, colorized PNG is for viewing because its rendering loses the cross-image scale needed by the frozen numeric cutoff. [Kendall and Gal](https://proceedings.neurips.cc/paper/2017/hash/2650d6089a6d640c5e85b2b88265dc2b-Abstract.html) and [entropy implementation](../../../shared/medclipseg/test.py).

**Account for prompt provenance.** The saved study uses the `original` workflow. The validation runner falls back to `Val_text.xlsx` when the suffixed workbook is unavailable. An audit of the available description columns found terms such as *benign* and *malignant* in the BUSI workbooks and every external test workbook. As a result, the reported metrics apply to the documented prompt workflow and leave performance under diagnosis-blind prompting unresolved. A neutral-prompt study needs its own frozen prompt policy and verification of the workbooks, checkpoint and case mappings used in the run. The dashboard request is separate. It selects actions over precomputed results. [Upstream prompt design](https://openaccess.thecvf.com/content/CVPR2026/supplemental/Koleilat_MedCLIPSeg_Probabilistic_Vision-Language_CVPR_2026_supplemental.pdf), [validation runner](../experiments/validation_selection/run_validation_inference.py), and [experimental protocol](EXPERIMENTAL_PROTOCOL.md).

## Aggregation, metrics and operating policy

For a mask with foreground and background, let `α` be the predicted foreground pixel fraction. The full-image average obeys `U_mean = α U_fg + (1−α) U_bg`. The equation explains why a small, uncertain prediction can have a low global score when background uncertainty is low. Conditioning on predicted foreground removes the explicit area mixing weight. The resulting score still depends on which pixels the model predicts as foreground. [Roy et al., structure-wise uncertainty](https://doi.org/10.1016/j.neuroimage.2019.03.042), [Guarino et al., spatial aggregation](https://openaccess.thecvf.com/content/CVPR2026/html/Guarino_Better_than_Average_Spatially-Aware_Aggregation_of_Segmentation_Uncertainty_Improves_Downstream_CVPR_2026_paper.html), and [theory and definitions](THEORY_AND_METRICS.md).

| Score | Purpose of the comparison | Limitation |
| --- | --- | --- |
| `U_mean` | Whole-image baseline for testing spatial conditioning. | Low-uncertainty background can dominate. |
| `U_positive` | Test whether excluding numerically zero pixels improves the baseline. | Tiny positive values can enter regardless of anatomy. |
| `U_fg` | Mean over the predicted lesion to reduce background dilution. | Undefined for empty masks and insensitive to omitted areas. |
| `U_boundary` | Dilation minus erosion tests contour ambiguity with a square 5 × 5 kernel. | Fixed pixel width has different physical meanings across scans. |
| `U_threshold` | Conditional mean above 0.1 nats tests the high-entropy tail without using a mask. | Can be undefined and depends on the chosen entropy threshold. |
| `U_std_fg` | Population standard deviation tests spatial dispersion. | Uniformly high foreground entropy can have low dispersion. |
| `U_ratio` | Foreground-to-global ratio tests relative contrast. | Small denominators amplify differences and may preserve area dependence. |

**Separate overlap, boundary agreement and ranking.** Dice similarity measures foreground overlap. Normalized Surface Dice measures agreement within a surface tolerance. The test evaluator assumes unit pixel-grid spacing and tolerance 2. A physical tolerance in millimeters would require acquisition spacing. Spearman evaluates monotonic association. Empirical risk–coverage and AURC of `1−DSC` evaluate the intended decision of retaining low-score cases. Random retention is the no-information control. The oracle orders by observed reference loss and gives the best achievable empirical ranking on those cases. Paired bootstrap resamples cases jointly across methods. Dependence among images from the same patient could require patient-level resampling. [Nikolov et al., surface Dice](https://arxiv.org/abs/1809.04430), [Geifman and El-Yaniv, selective prediction](https://arxiv.org/abs/1705.08500), and [metric conventions](THEORY_AND_METRICS.md).

**Use the validation evidence to select `U_fg`.** Validation AURC was 0.0839 for `U_fg`, 0.0850 for `U_std_fg` and 0.1438 for `U_mean`. Foreground mean also had a much smaller magnitude of association with predicted area than global mean in those cases. The paired comparison gave `ΔAURC=-0.0011` for foreground mean versus foreground dispersion, with 95% interval `[-0.0033, 0.0008]` and empirical p-value 0.294. Thus the foreground mean had the lowest point estimate and a direct interpretation. The comparison with dispersion remains unresolved. The historical rationale strings in the frozen YAML and JSON contain a different interval and p-value. The rerun reproduced the bundled paired CSV byte for byte. Use the CSV for statistical inference and the numeric policy in YAML/JSON for the operating cutoff. [Method table](../experiments/validation_selection/results/validation_method_comparison_N65.csv), [paired bootstrap](../experiments/validation_selection/results/paired_bootstrap_aurc_ci.csv), and [area correlations](../experiments/validation_selection/results/lesion_area_correlation.csv).

**Freeze a review budget and handle undefined foreground scores.** An 80% validation target expresses a nominal one-in-five review budget. The validation quantile gave `0.064058324` nats and retained 52/65 cases. This is a protocol choice among the evaluated coverages. Clinical operating capacity would need its own assessment. For an empty predicted mask, foreground mean is undefined. The separate rule `U_mean ≤ 10⁻⁴` gives the empty-mask branch an explicit near-zero tolerance. The available BUSI cases support an observed policy comparison. They do not identify an optimal tolerance for unobserved confident misses. A confident missed lesion can pass that branch. [Validation targets](../experiments/validation_selection/results/calibrated_abstention_thresholds.csv), [empty-mask policies](../experiments/validation_selection/results/empty_mask_policy_evaluation.csv), and [numeric policy](../experiments/validation_selection/frozen_selective_prediction_config.yaml).

**Interpret transfer with the realized coverage.** The frozen rule retained 47/65 BUSI test lesion cases and 238/464 external cases. Retained mean DSC was 0.9031 and 0.8718. A poor BUSI segmentation passed the gate, and the external cohort contained no predicted-empty case to estimate the missed-lesion rate of that branch. The calibration, locked test and external analyses were rerun from saved per-image inference outputs and reproduced the principal aggregate results. This verifies the post-processing and statistical chain for those artifacts. Repeating the full image-to-mask workflow on another device is a separate reproducibility test. [Cross-domain results](../experiments/external_test/results/cross_domain_summary.csv) and [evidence and limitations](SCIENTIFIC_EVIDENCE_AND_CLAIMS.md).
